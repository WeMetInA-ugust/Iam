# The Wheels on the Bus — Separate Cinematic Edition

The original files remain unchanged. Open `cinematic.html` to view the separate redesigned edition.

To serve locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/cinematic.html`.

This edition uses a 16:9 responsive cinematic composition, atmospheric painted scenery, a lounging fuzzy black cat, lyric-only text treatment, and separate high-speed, yawn, and sleep gestures.
