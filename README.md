# The Wheels on the Bus — Kids Cat Sing-Along

A self-contained, cute 16:9 lyrics-only animated sing-along inspired by soft Japanese watercolor children's art.

## Run

Open `index.html` in a modern browser, or serve the repository locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- 16:9 responsive animation
- Three-minute timed verse sequence
- Soft watercolor palette and subtle pink ink accents
- Prominent animated black cat instructor
- Beat-matched head bobbing and tail swinging
- Highlighted lyric timing
- Gentle generated sound effects; no copyrighted music or external assets
